# 外部上传素材图编辑生成接口说明

本文档给外部投放系统开发人员使用，说明如何直接上传一张素材图，并配合 prompt 在该图片基础上生成新的广告图片。

## 1. 基础信息

接口基础地址：

```text
https://ai.ggcss.xyz
```

鉴权方式沿用 `AI_ADS_ACCESS_TOKEN`：

```http
Authorization: Bearer <AI_ADS_ACCESS_TOKEN>
```

也支持把 token 放在 URL 查询参数中：

```text
?ai_access_token=<AI_ADS_ACCESS_TOKEN>
```

请求格式必须是：

```http
Content-Type: multipart/form-data
```

## 2. 上传素材图并创建编辑任务

接口：

```http
POST https://ai.ggcss.xyz/api/v1/integrations/image-generation/edits
```

multipart 字段：

| 字段 | 类型 | 是否必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `image` | file | 是 | 无 | 上传的素材图文件，支持常见图片 MIME 类型。 |
| `prompt` | string | 是 | 无 | 基于素材图的编辑生成要求。 |
| `external_request_id` | string | 否 | 无 | 外部系统请求 ID，用于幂等，最大 128 字符。 |
| `count` | integer | 否 | `1` | 生成图片数量，范围 `1` 到 `5`。 |
| `size` | string | 否 | `1:1` | 图片比例或尺寸标识，例如 `1:1`、`9:16`。 |
| `model_id` | string | 否 | 系统默认图片模型 | 指定图片模型，最大 128 字符。 |

文件限制：

- `image` 必须是图片类型，例如 `image/png`、`image/jpeg`、`image/webp`、`image/gif`。
- 文件大小不能超过系统配置 `IMAGE_DOWNLOAD_MAX_BYTES`，当前示例配置为 `26214400` 字节。

请求示例：

```bash
curl -X POST "https://ai.ggcss.xyz/api/v1/integrations/image-generation/edits" \
  -H "Authorization: Bearer <AI_ADS_ACCESS_TOKEN>" \
  -F "image=@source.png;type=image/png" \
  -F "prompt=保留产品主体，把背景改成明亮的广告棚拍风格" \
  -F "count=1" \
  -F "size=1:1" \
  -F "external_request_id=image-edit-20260707-001"
```

创建成功返回 HTTP `202`：

```json
{
  "code": 1001,
  "message": "processing",
  "data": {
    "job_id": "uploaded-edit-job-id",
    "status": "processing",
    "count": 1,
    "size": "1:1",
    "mode": "from_image"
  }
}
```

返回字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.job_id` | string | 新创建的图片编辑任务 ID。 |
| `data.status` | string | 当前状态，创建成功后为 `processing`。 |
| `data.mode` | string | `from_image` 表示本任务来自外部上传素材图。 |

## 3. 查询生成结果

结果沿用现有图片任务轮询接口：

```http
GET https://ai.ggcss.xyz/api/v1/integrations/image-generation/jobs/{job_id}
```

这里的 `{job_id}` 是上传接口返回的 `data.job_id`。

处理中返回：

```json
{
  "code": 1001,
  "message": "processing",
  "data": {
    "job_id": "uploaded-edit-job-id",
    "status": "processing",
    "count": 1,
    "size": "1:1",
    "mode": "from_image",
    "images": []
  }
}
```

成功返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "job_id": "uploaded-edit-job-id",
    "status": "succeeded",
    "count": 1,
    "size": "1:1",
    "mode": "from_image",
    "images": [
      {
        "index": 1,
        "url": "https://ai.ggcss.xyz/storage/images/external_image_generation/uploaded-edit-job-id/1.png",
        "prompt": "保留产品主体，把背景改成明亮的广告棚拍风格"
      }
    ]
  }
}
```

失败返回：

```json
{
  "code": 5001,
  "message": "image generation failed",
  "data": {
    "job_id": "uploaded-edit-job-id",
    "status": "failed",
    "count": 1,
    "size": "1:1",
    "mode": "from_image",
    "images": [],
    "error": "provider error message"
  }
}
```

## 4. 生成行为说明

系统会把上传的素材图保存为内部源图，并在异步任务执行时转换为 data URL，作为图片编辑接口的底图。

当当前图片供应商支持编辑并开启 `MODEL_GATEWAY_IMAGE_EDIT_ENABLED=true` 时，系统会调用网关的图片编辑接口：

```text
上传素材图 + prompt -> /images/edits -> 新图片
```

如果当前供应商不支持图片编辑，系统仍会使用 prompt 走文生图降级路径。降级时不能保证保留上传素材图的细节。

## 5. 错误码说明

| HTTP 状态 | `code` | `message` 示例 | 说明 |
| --- | --- | --- | --- |
| `202` | `1001` | `processing` | 任务已创建，正在异步生成。 |
| `400` | `4001` | `request validation failed` | 缺少文件、缺少 prompt 或字段类型不合法。 |
| `400` | `4001` | `Unsupported image content type` | 上传文件不是支持的图片类型。 |
| `400` | `4001` | `Uploaded image exceeds configured size limit` | 上传图片超过大小限制。 |
| `401` | `4003` | `invalid or missing access token` | token 缺失或错误。 |
| `500` | `5001` | `provider error message` | 图片供应商或存储处理异常。 |

## 6. 调用建议

1. 外部系统应保存返回的 `job_id`，并用轮询接口查询结果。
2. `prompt` 尽量说明“保留什么、修改什么”，例如“保留产品主体，只替换背景和光线”。
3. 如果网络重试同一次上传请求，建议复用同一个 `external_request_id`。
4. 上传文件只作为 AI 系统内部编辑底图保存，最终投放应使用轮询结果里的生成图片 URL。
5. 不要把真实 token 写进前端代码、日志、截图或公开文档。

# 品牌安全策略设计：禁止赌博、博彩、药品、金钱和价格优势表达

## 背景

当前系统定位是辅助运营人员生成广告选题、文案、图片、视频和最终预审包，再由外部投放系统使用回传 JSON 做广告投放。用户确认新的业务安全规则：

- 文案、图片、视频不能和赌博、博彩、药品有关联。
- 文案、图片、视频不能带有货币、现金、支付、赚钱、收益等金钱相关表达或画面。
- 折扣、低价、优惠、便宜、免费、促销、特价、省钱、划算、性价比等价格优势型营销词也不能出现。

这些规则需要作为系统级硬约束，而不是依赖运营人员每次在提示词里手动提醒。

## 目标

1. 在选题、文案、图片 brief、图片生成 prompt、视频 storyboard、视频生成 prompt 中统一加入品牌安全约束。
2. 在预审包确认回传前执行品牌安全检查，命中高风险内容时阻止确认回传。
3. 给运营人员清晰展示命中的风险项、位置和建议替代表达。
4. 保持第一版实现轻量、可测试、可部署，后续再加入图片视觉审核和视频关键帧审核。

## 非目标

第一版不做真实图片识别和视频画面识别。第一版主要覆盖文本、图片 brief、图片 prompt、视频 storyboard、视频 prompt 这些可控文本层。真实图片和视频关键帧的多模态审核放到第二阶段。

第一版不改变外部系统对接协议，不改变 `result_payload` 的主结构。品牌安全结果可以作为预审包内部审核状态和元数据存在，避免破坏已对接字段。

## 推荐方案

采用“统一品牌安全策略 + 生成前约束 + 生成后扫描 + 回传前阻断”的方案。

### 统一策略

新增一个后端品牌安全策略模块，例如 `backend/app/services/brand_safety_policy.py`。它负责维护禁止类别、关键词、正则表达式、替代表达和扫描函数。

策略分为四类：

1. 赌博/博彩：赌博、博彩、下注、投注、赔率、赌场、老虎机、轮盘、扑克、筹码、彩票、中奖、娱乐城、casino、bet、betting、jackpot、lottery 等。
2. 药品/医疗药物：药品、药物、处方药、药片、胶囊、注射器、药瓶、药房、治疗、疗效、治愈、降压、止痛、抗生素、medicine、drug、pill、capsule、pharmacy 等。
3. 金钱/货币：现金、货币、硬币、钞票、银行卡、钱包、支付、付款、收款、价格、金额、收益、赚钱、利润、投资、返现、美元、人民币、money、cash、coin、price、profit 等。
4. 价格优势营销：折扣、低价、便宜、优惠、促销、满减、立减、特价、免费、低至、仅需、超值、划算、省钱、性价比、抢购、购买立减、discount、cheap、free、sale、deal、promo 等。

命中以上任一类，第一版均按 `high` 风险处理。

### 生成前约束

扩展现有 `backend/app/integrations/llm/compliance.py`，在全局合规提示中加入品牌安全规则。所有内容生成调用已经通过 `with_meta_ad_compliance(...)` 包裹，适合在这里统一增强。

图片生成还需要扩展 `backend/app/integrations/image/volcengine_provider.py` 中的最终 prompt，明确禁止模型生成现金、货币符号、银行卡、价格标签、折扣贴纸、促销标签、筹码、药片、胶囊、药瓶等视觉元素。

视频生成需要扩展 storyboard 到 prompt 的转换逻辑，禁止字幕、旁白和画面描述出现这些主题或视觉元素。

### 生成后扫描

在生成完成后，对以下内容统一扫描：

- 选题标题、角度、卖点、风险说明。
- 文案正文、标题、描述、CTA。
- 图片 brief 的标题、画面文字、画面方向。
- 图片最终 prompt。
- 视频 storyboard 的画面、字幕、动作、旁白、备注。
- 视频最终 prompt。

扫描输出一个结构化结果：

```json
{
  "status": "blocked",
  "highest_severity": "high",
  "findings": [
    {
      "category": "price_promotion",
      "severity": "high",
      "field_path": "copy.headline",
      "matched_text": "低价",
      "suggestion": "改为强调体验、清晰度、稳定性或上手效率"
    }
  ]
}
```

### 回传前阻断

在 `confirm_review` 或其前置确认流程中加入品牌安全检查。如果存在 `high` 风险：

- 后端拒绝确认回传，返回明确错误。
- 前端禁用或拦截“确认并回传”。
- 预审页显示风险类别、命中字段、命中文本和替代方向。
- 运营人员可以修改或重新生成后再次检查。

这能保证外部系统拿到的最终 JSON 不包含已知高风险内容。

## 安全替代表达

当系统需要替换价格或金钱表达时，优先引导到非价格价值：

- 体验更顺畅
- 操作更简单
- 内容更清晰
- 适合日常使用
- 快速上手
- 稳定可靠
- 查看详情
- 立即体验
- 了解更多

不得替换成“更便宜”“更划算”“免费体验”“限时优惠”等价格优势表达。

## 数据流

1. 外部系统跳转进入 AI 系统创建工单。
2. AI 系统生成选题、文案、图片 brief、图片、视频 storyboard 和视频。
3. 每个生成阶段使用品牌安全提示词降低违规概率。
4. 生成完成后扫描预审包文本层内容。
5. 前端预审页显示品牌安全检查结果。
6. 如果无高风险，允许确认并回传。
7. 如果有高风险，阻止确认回传，并提示修改或重新生成。

## 错误处理

品牌安全扫描本身失败时，不能默认放行。第一版按 fail-closed 处理：返回“品牌安全检查不可用，请稍后重试或联系管理员”，并阻止确认回传。

如果用户输入或外部工单本身包含禁止内容，系统不应原样延续到生成结果。生成提示词要要求模型保留业务意图，但改写为中性、非价格、非博彩、非药品、非金钱表达。

## 测试策略

后端测试：

- 合规提示词包含赌博、博彩、药品、金钱、价格优势禁止规则。
- 品牌安全扫描能识别中文和英文禁词。
- 折扣、低价、优惠、免费、便宜、促销、性价比命中 `price_promotion` 高风险。
- 赌博、博彩、筹码、赌场、下注命中 `gambling` 高风险。
- 药片、胶囊、处方药、药房、疗效命中 `medicine` 高风险。
- 现金、银行卡、支付、收益、赚钱、货币符号命中 `money` 高风险。
- `confirm_review` 在存在高风险时拒绝回传。
- 安全内容可以通过检查。

前端测试：

- 预审页展示风险类别、字段和建议。
- 有高风险时确认回传按钮不可用或提交后显示后端错误。
- 无高风险时保持原有确认回传流程。

## 分阶段实施

第一阶段：

- 增加统一品牌安全策略模块。
- 扩展 LLM 合规提示词。
- 扩展图片和视频生成 prompt 的负面约束。
- 增加文本层扫描和回传前阻断。
- 在预审页显示检查结果。

第二阶段：

- 对生成图片调用多模态审核或视觉标签检测。
- 检测现金、货币符号、价格标签、折扣贴纸、筹码、药片、药瓶等真实画面元素。

第三阶段：

- 对视频抽关键帧审核。
- 将品牌安全风险报告写入预审包或 artifact，便于外部系统和运营复盘。

## 验收标准

1. 生成提示词明确禁止赌博、博彩、药品、金钱和价格优势表达。
2. 输入或生成内容包含“低价”“折扣”“优惠”“免费”“促销”等词时，品牌安全检查返回高风险。
3. 高风险预审包不能确认并回传。
4. 无风险预审包仍可走完原有确认并回传流程。
5. 现有外部系统对接字段和结果接口保持兼容。

# 广告研究视觉评分重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将公开广告研究从“文本类别硬淘汰”改为“技术可用的短视频关键帧视觉评分 + 确定性 Top 25 排序”，提高回收率、缩短媒体处理时间，并在 24 小时结果窗口内保留可查看的封面与证据帧。

**Architecture:** 保留 `athm793/meta-ads-scraper` Collector、`external_user_id` 幂等、Celery/Redis 和轮询 API。Worker 将并发准备可访问视频：确认时长、下载短视频、生成封面/关键帧并放入共享的 `/data/storage/ad-research/<job_id>/`；`gpt-5.4-mini` 只接收帧与非文本媒体元数据，以 `reasoning_effort: "none"` 返回视觉分项。编排器对所有技术合格且评分成功的候选计算确定性分数、按稳定排序选 Top 25，并用高分候选的可见元素指导后续 query。

**Tech Stack:** Python 3.13、FastAPI、Pydantic、SQLAlchemy async、Celery、Redis、httpx、ffprobe/ffmpeg、Docker Compose、pytest、GPT Responses API。

## Global Constraints

- 首期 Collector 继续使用 `athm793/meta-ads-scraper`；不把采集器逻辑耦合到分类业务规则。
- 外部请求仅使用 `external_user_id`、`country`、`category`、可选 `keywords`、`target_count`；不增加外部质量阈值字段。
- 硬条件仅为 `ACTIVE`、公开视频可访问、`active_days >= 1`、最终确认 `duration_seconds <= 30`、广告 ID 去重、至少一张可分析图像。
- `AD_RESEARCH_WORKER_CONCURRENCY=2`、`AD_RESEARCH_MODEL_CONCURRENCY=6` 保持不变；新增 `AD_RESEARCH_MEDIA_CONCURRENCY=6`、`AD_RESEARCH_FRAME_CONCURRENCY=4`。
- 模型固定为 `gpt-5.4-mini`，调用必须是 `reasoning: {"effort": "none"}`。
- 视觉模型请求不得含标题、正文、CTA、广告主/主页名称、落地页 URL、域名或原始广告文本；它们只能作为最终展示字段。
- 不访问广告落地页，不模拟用户/审核，不验证或确认 Cloaking，不推断花费、CPA、ROAS、转化或盈利。
- 仅保留最终入选广告的封面/证据帧与结果 24 小时；未入选候选及失败任务的本地媒体立即清理。
- 不提交 `AGENTS.md`、`.env*`、密钥、Token、运行时媒体目录或其他主工作区未完成改动。
- 不需要 Alembic 迁移：本次任务沿用 `AdResearchJob.result_json`、`summary_json` 和 `progress_json`。

## 统一数据契约

在 `backend/app/services/ad_research_media.py` 定义以下数据类型，避免在编排器中传递松散字典：

```python
@dataclass(frozen=True)
class PreparedAdMedia:
    cover_url: str | None
    cover_source: Literal["original_thumbnail", "generated_frame"] | None
    frame_urls: tuple[str, ...]
    local_frame_paths: tuple[Path, ...]
    duration_source: Literal["collector", "remote_ffprobe", "downloaded_ffprobe"] | None
    duration_probe_attempts: int


@dataclass(frozen=True)
class TechnicalQualification:
    qualified: bool
    reasons: tuple[str, ...]
    duration_seconds: float | None
    active_days: int | None
    media: PreparedAdMedia | None = None
```

`PreparedAdMedia.local_frame_paths` 仅在 Worker 内使用，绝不序列化进 API；`cover_url` 与 `frame_urls` 必须是 `/storage/...` 下的本系统公开 URL，且只能保留到任务过期。

在 `backend/app/services/ad_research_model.py` 统一使用：

```python
VisualScore = dict[str, Any]

async def score_visual(
    self,
    *,
    category: str,
    candidate: CollectorAd,
    media: PreparedAdMedia,
) -> VisualScore: ...
```

成功结果必须包含：

```python
{
  "core_gambling_points": 0.0,
  "reward_ui_points": 0.0,
  "gambling_style_points": 0.0,
  "casino_context_points": 0.0,
  "media_quality_points": 0.0,
  "analysis_confidence": 0.0,
  "visible_elements": [],
  "visual_evidence": [{"frame_index": 1, "description": "..."}],
  "uncertain": false
}
```

分项上限固定为 `40/20/15/10/5`；`analysis_confidence` 固定裁剪到 `0.0–1.0`；`visible_elements` 最多 12 个、每个最多 80 字符；`visual_evidence` 最多 5 条，`frame_index` 必须在本次实际发送帧编号范围内。

后台总分函数固定为：

```python
def public_continuity_points(active_days: int | None) -> float:
    days = max(int(active_days or 0), 0)
    if days >= 30:
        return 10.0
    if days >= 14:
        return 7.0
    if days >= 7:
        return 5.0
    if days >= 3:
        return 3.0
    return 1.0 if days >= 1 else 0.0


def final_score(visual: VisualScore, active_days: int | None) -> tuple[float, float, float]:
    visual_total = min(90.0, sum(float(visual[name]) for name in (
        "core_gambling_points", "reward_ui_points", "gambling_style_points",
        "casino_context_points", "media_quality_points",
    )))
    continuity = public_continuity_points(active_days)
    return min(100.0, visual_total + continuity), visual_total, continuity
```

- [ ] **Step 3: 以单广告可恢复链路实现 `inspect`**

实现顺序必须为：

```python
async def inspect(self, ad: CollectorAd, *, job_id: str) -> TechnicalQualification:
    reasons = self._base_reasons(ad)  # ACTIVE、公开视频 URL、active_days；不检查 thumbnail
    if reasons:
        return TechnicalQualification(False, tuple(reasons), ad.duration_seconds, ad.days_running)

    duration, source, attempts = await self._resolve_duration(ad)
    if duration is None:
        return TechnicalQualification(False, ("duration_unavailable",), None, ad.days_running)
    if duration > MAX_VIDEO_SECONDS:
        return TechnicalQualification(False, ("duration_over_30",), duration, ad.days_running)

    artifact_dir = self._artifact_dir(job_id, ad.ad_library_id)
    downloaded_video = await self._download_video(ad.video_url, artifact_dir)
    if downloaded_video is None:
        return TechnicalQualification(False, ("video_download_failed",), duration, ad.days_running)

    cover, frames = await self._prepare_cover_and_frames(ad, downloaded_video, artifact_dir, duration)
    if not frames:
        return TechnicalQualification(False, ("no_analyzable_visual",), duration, ad.days_running)
    return TechnicalQualification(True, (), duration, ad.days_running, PreparedAdMedia(...))
```

`_resolve_duration()` 必须依次使用：合法的 Collector 时长、一次远程 `ffprobe`、两次退避重试的远程 `ffprobe`、临时下载后本地 `ffprobe`。将每次远程尝试计入 `duration_probe_attempts`；本地探测仍失败时返回 `None`。每个 subprocess 超时后都必须 `kill()` 并 `await wait()`。

下载使用现有 `download_public_http_file()`，带 Task 1 的字节上限、超时和重试参数；下载前仍执行 `validate_public_http_url()`，不跟随或访问任何广告落地页。

def _frame_seconds(duration: float, *, low_confidence: bool = False) -> tuple[float, ...]:
    ratios = (0.20, 0.50, 0.80, 0.35, 0.65) if low_confidence else (0.20, 0.50, 0.80)
    return tuple(min(max(duration * ratio, 0.0), max(duration - 0.05, 0.0)) for ratio in ratios)

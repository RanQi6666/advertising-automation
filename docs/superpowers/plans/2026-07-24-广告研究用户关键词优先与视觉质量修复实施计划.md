# 广告研究用户关键词优先与视觉质量修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变外部请求合同的前提下，实现用户关键词优先的动态查询、以博彩游戏视频画面为核心的评分、模型失败补偿和质量驱动补采；公开源存在足够唯一技术候选时精确返回 25 条。

**Architecture:** 保留 FastAPI + Celery + Redis + Meta Ads Collector 异步链路。GPT-5.4-mini 只负责查询规划和视觉语义识别；新建纯函数模块负责分数求和、负向上限、质量判断、排序和补位；媒体层并发准备时长、封面、关键帧联系表；编排器按查询来源并发采集并对失败评分做补偿。

**Tech Stack:** Python 3.12、FastAPI、Pydantic v2、SQLAlchemy Async、Celery、Redis、httpx、Pillow、ffmpeg/ffprobe、pytest、pytest-asyncio、ruff、Docker Compose、GPT-5.4-mini Responses API。

## Global Constraints

- 外部请求仍为 `external_user_id`、`country`、`category`、可选 `keywords`、`target_count`；内部质量参数不由外部系统提供。
- `external_user_id` 继续幂等；外部系统轮询，结果保留 24 小时，不增加确认获取接口。
- 每个用户原词至少执行一次 `user_exact`；模型只能扩展，不能覆盖或删除原词。
- 有用户词时默认预算 `user_exact=20%`、`user_expanded=60%`、`model_exploration=20%`；原词多于 20% 配额时先保证每词一次。
- 多个用户词独立建组，不强制全部 AND；用户词不增加视觉分，只在所有视觉主排序字段完全相同后作为 tie-break。
- 核心视觉评分只接收 `category`、`duration_seconds`、PreparedAdMedia；不传标题、正文、CTA、广告主、URL 或关键词。
- 固定 `gpt-5.4-mini`、`reasoning_effort="none"`；Worker 默认并发 2，模型默认全局并发 6。
- 硬条件：视频、ACTIVE、投放 `>=1` 天、时长可确认且 `<=30` 秒、原始或生成封面、广告 ID 唯一。
- 默认用封面、开头、中间、后段帧组成 2×2 联系表并单次评分；联系表失败才回退独立帧。
- 正常最多 6 轮/650 条；保证数量最多 10 轮/1200 条。
- 只有 `qualified_visual_count >= target_count` 才提前停止；P4 达标不能提前停止。
- 质量不足时允许唯一技术合格 P4 补位，标记 `is_fallback=true`、`fallback_reason="insufficient_high_relevance_candidates"`。
- 不复制、伪造或重复广告；公开源唯一技术候选不足时返回 `insufficient_source_inventory`。
- 不采集/推断花费、CPA、ROAS、转化或牌照，不访问 Cloaking 真实用户路径。
- 现有关键词、进度、摘要、结果列均为 JSON，预计无数据库迁移；实现中若发现不符，停止并报告。
- 不修改范围外前端；不提交 `AGENTS.md`、`.env*`、Token、Key、密码、SSH 私钥。
- 提交前执行 `git status --short`、`git diff --cached --check`；分支名和提交信息使用简体中文。

```python
def _normalize_planned_queries(planned, *, seed_keywords, country, category, round_number, max_queries=10):
    keywords = _unique_queries(seed_keywords)
    limit = min(max(int(max_queries), 1), 12)
    safe_round = _safe_round_number(round_number)
    output, seen = [], set()

    def add(query, intent, rationale, origin, parent=None, visuals=()):
        query = " ".join(str(query).split())
        if not query or query.casefold() in seen or len(output) >= limit:
            return
        seen.add(query.casefold())
        output.append(PlannedQuery(
            query_id=f"r{safe_round}_q{len(output)+1:02d}", query=query, intent=intent,
            rationale=rationale, expected_visuals=tuple(visuals),
            query_origin=origin, parent_keyword=parent,
        ))

    for keyword in keywords:
        add(keyword, "game_gambling", "Execute the original user keyword.", "user_exact", keyword)
    if not keywords:
        for item in planned:
            origin = item.query_origin if item.query_origin in {"model_exploration", "model_recovery"} else "model_exploration"
            add(item.query, item.intent, item.rationale, origin, visuals=item.expected_visuals)
        add(f"{category} {country}", "local_exploration", "Deterministic recovery.", "model_recovery")
        return tuple(output)

    user_target = min(limit, max(len(keywords), ceil(limit * .8)))
    for item in planned:
        if item.query_origin != "user_expanded" or item.parent_keyword not in keywords:
            continue
        add(item.query, item.intent, item.rationale, "user_expanded", item.parent_keyword, item.expected_visuals)
        if sum(q.query_origin.startswith("user_") for q in output) >= user_target:
            break
    suffixes, index = (category, country, f"{category} {country}"), 0
    while sum(q.query_origin.startswith("user_") for q in output) < user_target:
        parent = keywords[index % len(keywords)]
        suffix = suffixes[(index // len(keywords)) % len(suffixes)]
        add(f"{parent} {suffix}", "game_gambling", "User-keyword recovery expansion.", "user_expanded", parent)
        index += 1
    for item in planned:
        if item.query_origin in {"model_exploration", "model_recovery"}:
            add(item.query, item.intent, item.rationale, item.query_origin, visuals=item.expected_visuals)
    add(f"{category} {country}", "local_exploration", "Model recovery query.", "model_recovery")
    return tuple(output[:limit])
```

在模型 schema/prompt 中要求 `query_origin`、`parent_keyword`；解析非法来源或用户族缺 parent 的项时丢弃，再调用归一函数补齐。fallback 同样调用归一函数，保证原词存在。

```python
from typing import Any

COMPONENT_LIMITS = {"gameplay_ui":35,"betting_mechanism":25,"in_game_value_ui":15,"gambling_style":10,"visual_clarity":10,"media_quality":5}
PRIORITY_RANK = {"game_gambling":3,"sports_betting":2,"gambling_adjacent":1,"unrelated":0}
NEGATIVE_CAPS = {"recruitment_income":8,"money_wallet_only":10,"story_talking_head":12,"ordinary_game":24,"weak_gambling_game":49}

def bounded(value, maximum):
    return min(max(float(value), 0), maximum) if isinstance(value, (int,float)) and not isinstance(value,bool) else 0.0

def validate_visual_score(data: Any, *, frame_count: int):
    payload = data if isinstance(data, dict) else {}
    priority = payload.get("visual_priority") if payload.get("visual_priority") in PRIORITY_RANK else "unrelated"
    negative = payload.get("negative_visual_type") if payload.get("negative_visual_type") in {"none", *NEGATIVE_CAPS} else "none"
    game, betting = payload.get("game_context_present") is True, payload.get("betting_context_present") is True
    money_only = payload.get("money_only_promo") is True
    source = payload.get("component_scores") if isinstance(payload.get("component_scores"), dict) else {}
    components = {key: round(bounded(source.get(key), maximum), 2) for key, maximum in COMPONENT_LIMITS.items()}
    if money_only and not game: negative = "money_wallet_only"
    if priority == "gambling_adjacent" and not game: priority = "unrelated"
    if priority == "game_gambling" and not (game and betting): priority = "gambling_adjacent" if game else "unrelated"
    if priority == "sports_betting" and not betting: priority = "unrelated"
    total = min(sum(components.values()), NEGATIVE_CAPS.get(negative, 100))
    return {"visual_priority":priority,"game_context_present":game,"betting_context_present":betting,
        "money_only_promo":money_only,"negative_visual_type":negative,"component_scores":components,
        "analysis_confidence":round(bounded(payload.get("analysis_confidence"),1),4),
        "visual_evidence":payload.get("visual_evidence",[])[:8] if isinstance(payload.get("visual_evidence"),list) else [],
        "retrieval_hints":payload.get("retrieval_hints",[])[:8] if isinstance(payload.get("retrieval_hints"),list) else [],
        "frame_count":max(int(frame_count),0),"visual_total":round(total,2)}

def is_quality_candidate(score):
    return score.get("visual_priority") in {"game_gambling","sports_betting"} or (score.get("visual_priority") == "gambling_adjacent" and score.get("game_context_present") is True)
```

```python
class GatewayHealthTracker:
    def __init__(self, *, window_size, error_threshold, recovery_successes):
        self.events=deque(maxlen=window_size); self.threshold=error_threshold
        self.recovery_successes=recovery_successes; self.degraded=False; self.streak=0
    def record(self, *, success):
        self.events.append(success); self.streak=self.streak+1 if success else 0
        if self.degraded and self.streak >= self.recovery_successes:
            self.degraded=False; self.events.clear(); return
        if len(self.events)==self.events.maxlen and sum(not x for x in self.events)/len(self.events)>=self.threshold:
            self.degraded=True
    def current_limit(self, base_limit):
        return min(max(int(base_limit),1),2) if self.degraded else max(int(base_limit),1)
```

`_wait_for_lease()` 使用 tracker 动态 limit。`_complete_json()` 外层循环捕获：429/500/502/503/504、ConnectTimeout、ReadTimeout、ConnectError、首次 JSONDecodeError 时重试；其他 4xx 立即抛 `ProviderError("... permanent failure: HTTP n")`。最终可重试失败抛 `ProviderError("... retryable failure exhausted: Type")`。每次 attempt 内调用 `_complete_json_once()`，后者负责单次 lease 和 client 生命周期，禁止三次尝试共持一个 lease。

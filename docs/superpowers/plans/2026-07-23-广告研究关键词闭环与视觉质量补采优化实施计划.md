# 广告研究关键词闭环与视觉质量补采优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 通过结构化关键词复盘和纯视觉优先级评分，让公开 Meta 广告研究任务稳定返回精确数量的短视频广告；总已评分技术候选不足目标数量时明确失败，不返回部分成功。

**Architecture:** 继续用 `athm793/meta-ads-scraper`，经 `MetaAdsBridgeAdapter` 只按国家和查询词召回公开广告。`AdResearchModel` 分别负责结构化查询计划和只接收视觉资料的六维评分；`AdResearchOrchestrator` 保存查询归因、生成查询级指标、执行 6 轮补采并按 P1→P4 选取；`AdResearchService` 只持久化精确完成或失败，历史 `insufficient` 只保留读取与过期兼容。

**Tech Stack:** Python 3.12、FastAPI、Pydantic、SQLAlchemy Async、Celery、Redis 分布式租约、httpx Responses API、FFmpeg/ffprobe、pytest、Ruff、Docker Compose。

## Global Constraints

- Collector 固定为 `athm793/meta-ads-scraper` 和项目内 `MetaAdsBridgeAdapter`；不访问落地页、不模拟用户、不跟随跳转、不探测 Cloaking 或非公开内容。
- 外部契约不变：`POST /api/v1/integrations/ad-research/jobs` 以 `external_user_id` 幂等；`GET /api/v1/integrations/ad-research/jobs/{task_id}` 轮询；结果保留 24 小时；不增加 callback、确认接口或 migration。
- 新任务终态只有 `completed`、`failed`、`expired`。`completed => len(ads) == target_count`；当前 `target_count=25` 时必须精确返回 25 条。历史 `insufficient` 可轮询、可过期清理，但不得由新任务产生。
- 技术合格：ACTIVE、有可下载视频、最终时长 `<=30.0s`、投放至少 1 天、有封面/关键帧且模型评分成功。复用现有并发媒体检查、封面生成、时长重试和低置信度补帧，不重构 `ad_research_media.py`。
- 模型由 `AD_RESEARCH_MODEL=gpt-5.4-mini` 配置，Responses 请求固定 `reasoning.effort="none"`；保持 Worker 并发 2、模型全局并发 6。
- 视觉模型仅接收类别、已确认时长、封面/关键帧、帧数；不得收到文案、标题、CTA、广告主、URL、来源关键词、`active_days`、持续投放分数。
- 排序：`game_gambling > sports_betting > gambling_adjacent > unrelated`，随后视觉总分、置信度、`active_days`、帧数、广告库 ID。`final_score = visual_total`，活跃天数不能补偿视觉弱相关广告。
- 预算：标准轮 1–4，定向补采轮 5–6，最多 6 轮、650 原始候选、50 条/查询；不再用第 25 名分数阈值决定是否完成。

# 外部素材生成接口使用说明

本文档给外部投放系统开发人员使用，说明如何调用 AI 系统生成文案、图片和视频素材。

## 1. 基础信息

接口基础地址：

```text
https://ai.ggcss.xyz
```

统一鉴权方式：

```http
Authorization: Bearer <AI_ADS_ACCESS_TOKEN>
Content-Type: application/json
```

也支持把 token 放在 URL 查询参数中：

```text
?ai_access_token=<AI_ADS_ACCESS_TOKEN>
```

统一返回格式：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

## 2. 通用请求参数

文案、图片、视频接口都支持以下基础参数。

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `external_request_id` | string | 否 | 外部系统请求 ID，用于幂等。重试同一次生成时建议保持不变。最大 128 字符。 |
| `product_name` | string | 是 | 产品名称或广告对象名称。最大 255 字符。 |
| `landing_url` | string | 否 | 落地页 URL，必须是合法 URL。 |
| `audience` | string | 否 | 目标受众描述。 |
| `country` | string | 否 | 投放国家或地区，例如 `US`。 |
| `event_name` | string | 否 | 外部系统优化事件名称，例如 `注册`、`快速注册`、`purchase`。 |
| `customEventType` | string | 否 | 外部系统需要的事件类型。如果不传，系统会根据 `event_name` 自动识别。 |
| `language` | string | 否 | 期望素材语言，例如 `zh-CN`、`en-US`。 |
| `brief` | string | 条件必填 | 素材生成需求描述。`brief` 和 `selling_points` 至少传一个。 |
| `selling_points` | string[] | 条件必填 | 产品卖点列表。`brief` 和 `selling_points` 至少传一个。 |
| `constraints` | object | 否 | 额外约束条件，JSON 对象。 |

事件识别规则：

| 外部传入事件 | 系统返回 `customEventType` |
| --- | --- |
| 包含 `注册`、`registration`、`register` | `COMPLETE_REGISTRATION` |
| 包含 `purchase`、`shop`、`order` | `PURCHASE` |
| 包含 `add_to_cart`、`cart` | `ADD_TO_CART` |
| 包含 `lead` | `LEAD` |
| 其他或未传 | `LINK_CLICK` |

素材安全限制：

- 不要传入赌博、博彩、赌场、中奖、筹码等相关内容。
- 不要传入药品、药物、药效、治疗、处方、注射等相关内容。
- 不要传入货币、现金、价格、付款、收益、投资等与钱相关内容。
- 不要传入折扣、低价、便宜、免费、促销、优惠券、限时优惠等营销词。
- 触发安全限制时，接口返回 `409` 和 `code = 4091`。

## 3. 文案生成接口

接口：

```http
POST https://ai.ggcss.xyz/api/v1/integrations/material-generation/copy
```

请求示例：

```json
{
  "external_request_id": "copy-20260625-001",
  "product_name": "Demo App",
  "landing_url": "https://example.com/landing",
  "audience": "New users who need a simple setup",
  "country": "US",
  "event_name": "快速注册",
  "language": "en-US",
  "brief": "Create clear ad copy for daily use.",
  "selling_points": ["Simple setup", "Clear content"],
  "constraints": {
    "tone": "clean and trustworthy"
  }
}
```

成功返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "request_id": "ai-copy-request-id",
    "primary_text": "Generated primary text",
    "headline": "Generated headline",
    "description": "Generated description",
    "cta": "Learn More",
    "customEventType": "COMPLETE_REGISTRATION"
  }
}
```

返回字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.request_id` | string | AI 系统内部文案请求 ID，可用于问题排查。 |
| `data.primary_text` | string | 广告主文案。 |
| `data.headline` | string | 广告标题。 |
| `data.description` | string/null | 广告描述。 |
| `data.cta` | string/null | 行动按钮文案。 |
| `data.customEventType` | string | 系统识别或外部传入的事件类型。 |

## 4. 图片生成接口

接口：

```http
POST https://ai.ggcss.xyz/api/v1/integrations/material-generation/images
```

图片专属参数：

| 参数 | 类型 | 是否必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `count` | integer | 否 | `1` | 生成图片数量，范围 `1` 到 `5`。 |
| `size` | string | 否 | `1:1` | 图片比例或尺寸标识，例如 `1:1`、`9:16`。 |

请求示例：

```json
{
  "external_request_id": "image-20260625-001",
  "product_name": "Demo App",
  "brief": "Create a clean product visual for daily use.",
  "selling_points": ["Simple setup", "Clear content"],
  "count": 2,
  "size": "1:1"
}
```

成功返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "request_id": "ai-image-request-id",
    "urls": [
      "https://ai.ggcss.xyz/storage/images/example-1.svg",
      "https://ai.ggcss.xyz/storage/images/example-2.svg"
    ]
  }
}
```

返回字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.request_id` | string | 本次图片生成请求 ID。 |
| `data.urls` | string[] | 生成后的图片访问地址。外部系统可直接保存或拉取。 |

## 5. 视频生成接口

视频是异步生成。外部系统先创建视频任务，再通过 `job_id` 查询结果。

### 5.1 创建视频任务

接口：

```http
POST https://ai.ggcss.xyz/api/v1/integrations/material-generation/videos
```

视频专属参数：

| 参数 | 类型 | 是否必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `image_urls` | string[] | 是 | 无 | 视频参考图片 URL 列表，至少传 1 个合法 URL。 |
| `duration_seconds` | integer | 否 | `6` | 视频时长，范围 `1` 到 `300` 秒。 |
| `aspect_ratio` | string | 否 | `9:16` | 视频比例，例如 `9:16`、`1:1`。 |
| `prompt` | string | 否 | 无 | 视频运动或画面要求。 |

请求示例：

```json
{
  "external_request_id": "video-20260625-001",
  "product_name": "Demo App",
  "brief": "Create a short video for daily use.",
  "image_urls": [
    "https://ai.ggcss.xyz/storage/images/example-1.svg"
  ],
  "duration_seconds": 6,
  "aspect_ratio": "9:16",
  "prompt": "Use a simple motion sequence."
}
```

创建成功返回 HTTP `202`：

```json
{
  "code": 1001,
  "message": "processing",
  "data": {
    "job_id": "ai-video-job-id",
    "status": "processing"
  }
}
```

返回字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.job_id` | string | 视频任务 ID，用于查询生成状态。 |
| `data.status` | string | 当前状态。创建成功后通常为 `processing`。 |

### 5.2 查询视频任务

接口：

```http
GET https://ai.ggcss.xyz/api/v1/integrations/material-generation/jobs/{job_id}
```

路径参数：

| 参数 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `job_id` | string | 是 | 创建视频任务返回的 `data.job_id`。 |

处理中返回：

```json
{
  "code": 1001,
  "message": "processing",
  "data": {
    "job_id": "ai-video-job-id",
    "status": "processing"
  }
}
```

成功返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "job_id": "ai-video-job-id",
    "status": "succeeded",
    "url": "https://ai.ggcss.xyz/storage/videos/example.mp4"
  }
}
```

失败返回：

```json
{
  "code": 5001,
  "message": "video generation failed",
  "data": {
    "job_id": "ai-video-job-id",
    "status": "failed",
    "error": "provider error message"
  }
}
```

## 6. 错误码说明

| HTTP 状态 | `code` | `message` 示例 | 说明 |
| --- | --- | --- | --- |
| `200` | `0` | `success` | 请求成功。 |
| `202` | `1001` | `processing` | 视频任务已创建，正在处理中。 |
| `400` | `4001` | `product_name is required` | 业务参数缺失或不合法。 |
| `400` | `4001` | `request validation failed` | JSON 格式、URL 类型、数值范围等校验失败。 |
| `401` | `4003` | `invalid or missing access token` | token 缺失或错误。 |
| `404` | `4001` | `video job not found` | 查询的视频任务不存在。 |
| `409` | `4091` | `brand safety check failed` | 请求内容或生成内容触发素材安全限制。 |
| `500` | `5001` | `provider unavailable` | AI 供应商或素材生成供应商异常。 |

品牌安全拦截返回示例：

```json
{
  "code": 4091,
  "message": "brand safety check failed",
  "data": {
    "brand_safety": {
      "status": "blocked",
      "highest_severity": "high",
      "findings": [
        {
          "category": "price_promotion",
          "severity": "high",
          "field_path": "$.brief",
          "matched_text": "discount",
          "suggestion": "Do not use discount, low-price, free, promo, sale, deal, coupon, or value-for-money language; emphasize experience instead."
        }
      ]
    }
  }
}
```

## 7. 调用建议

1. 文案和图片接口是同步返回，外部系统收到 `code = 0` 后即可使用 `data` 中的内容。
2. 视频接口是异步返回，创建任务成功后保存 `data.job_id`，再轮询查询接口。
3. 建议外部系统每次业务请求传 `external_request_id`，避免网络重试导致重复生成。
4. 接口调用失败时，先判断 `code`，不要只判断 HTTP 状态。
5. 外部系统不要把真实 token 写进前端代码、日志、截图或公开文档。

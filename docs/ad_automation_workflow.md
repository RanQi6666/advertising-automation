# AI 广告生产流程

## 当前主流程

```text
外部投放系统点击 AI 生成
-> 浏览器跳转到 AI 项目 /work-orders/new
-> 创建工单
-> LLM 识别/建议投放参数
-> 人工确认参数
-> 根据投放链接生成选题
-> 人工选择选题
-> 根据选题生成文案
-> 人工审核文案
-> 根据文案生成图片
-> 人工审核图片
-> 根据图片生成视频
-> 人工审核视频
-> 最终预审
-> 回传最终投放数据给外部投放系统
```

## 阶段产物

| 阶段 | 产物 | 说明 |
| --- | --- | --- |
| 工单创建 | `WorkOrder` | 保存原始工单、结构化字段和 LLM 识别结果。 |
| 参数确认 | `AdGenerationJob.result_payload` | 保存投放国家、年龄、人群、事件、落地页等建议值。 |
| 选题 | `Topic` | 根据工单和落地页生成多个投放角度，人工选择一个。 |
| 文案 | `CopyDraft` | 生成主文案、标题、描述，人工审核或修订。 |
| 图片 | `CreativeAsset` | 根据已审核文案生成图片素材，人工审核。 |
| 视频 | `VideoAsset` | 根据图片和文案生成视频任务，人工审核。 |
| 最终预审 | `AdGenerationJob` | 组装最终投放数据包，确认后状态变为 `returned`。 |

## 已移除职责

AI 项目不再负责 Meta OAuth、Facebook Page、Ad Account、Pixel 获取、创建发布任务、dry-run 发布、激活/暂停广告、同步 Meta 状态和 Insights 报表。

这些能力由外部投放系统负责。

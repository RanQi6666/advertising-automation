# 外部投放系统对接说明

本文给外部投放系统开发和运营联调使用。当前第一阶段采用“浏览器跳转进入 AI 系统 + 人工审核确认 + 浏览器回跳外部系统 + 外部系统按 job_id 拉取最终 JSON”的方式。

## 当前域名

AI 系统正式测试地址：

```text
https://ai.ggcss.xyz
```

外部投放后台地址：

```text
https://newpixel.messrocts.com
```

当前浏览器回跳接收接口：

```text
https://ads.ggcss.xyz/api/ai/receive_ai_ads
```

说明：`https://ads.ggcss.xyz/api/ai/receive_ai_ads` 是当前已配置在 AI 系统 `AI_ADS_RETURN_URL` 中的回跳接收地址。后续如果外部系统提供 `newpixel.messrocts.com` 下的新接收地址，再同步更新环境变量和本文档。

## 鉴权方式

AI 系统业务接口使用共享 token 保护。推荐接口调用使用：

```http
Authorization: Bearer <AI_ADS_ACCESS_TOKEN>
```

浏览器跳转入口使用：

```text
?ai_access_token=<AI_ADS_ACCESS_TOKEN>
```

兼容参数：

```text
?access_token=<AI_ADS_ACCESS_TOKEN>
```

不要把真实 token 写进仓库、文档截图或聊天记录。

## AI 创建入口

当前外部系统的 `AI创建` 按钮只需要做浏览器跳转：

```text
https://ai.ggcss.xyz/work-orders/new?ai_access_token=<AI_ADS_ACCESS_TOKEN>
```

当前入口没有传 `external_order_id` 或 `return_url`，因此 AI 系统会：

- 使用服务器环境变量 `AI_ADS_RETURN_URL` 作为默认回跳地址。
- 使用 AI 系统生成的 `job_id` 作为第一阶段联调主键。

后续如果外部系统可以追加外部订单号，推荐入口升级为：

```text
https://ai.ggcss.xyz/work-orders/new?ai_access_token=<AI_ADS_ACCESS_TOKEN>&external_order_id=<EXTERNAL_ORDER_ID>
```

## AI 生成与审核流程

运营人员进入 AI 系统后，流程为：

```text
创建工单
-> AI 识别并确认投放字段
-> 生成选题并审核
-> 生成文案并审核
-> 生成图片并审核
-> 生成视频并审核
-> 生成最终预审包
-> 点击“确认并回传”
```

任务状态会按以下阶段推进：

```text
queued
processing
fields_review
topic_review
copy_review
image_review
video_review
final_review
returned
failed
```

## 确认并回传

运营在 AI 系统点击“确认并回传”后：

1. AI 后端把任务状态标记为 `returned`。
2. 浏览器跳转到 `AI_ADS_RETURN_URL`。
3. 回跳 URL 会附带以下查询参数：

```text
job_id=<AI_JOB_ID>
status=returned
access_token=<AI_ADS_ACCESS_TOKEN>
ai_access_token=<AI_ADS_ACCESS_TOKEN>
external_order_id=<EXTERNAL_ORDER_ID 可选>
```

当前默认回跳示例：

```text
https://ads.ggcss.xyz/api/ai/receive_ai_ads?job_id=<AI_JOB_ID>&status=returned&access_token=<AI_ADS_ACCESS_TOKEN>&ai_access_token=<AI_ADS_ACCESS_TOKEN>
```

第一阶段外部系统应保存 `job_id`，并用它拉取最终 JSON。

## 拉取最终投放 JSON

外部系统收到回跳后，调用：

```http
GET https://ai.ggcss.xyz/api/v1/integrations/publishing/ad-generation/jobs/<AI_JOB_ID>/result
Authorization: Bearer <AI_ADS_ACCESS_TOKEN>
```

也支持 URL 参数鉴权：

```text
GET https://ai.ggcss.xyz/api/v1/integrations/publishing/ad-generation/jobs/<AI_JOB_ID>/result?ai_access_token=<AI_ADS_ACCESS_TOKEN>
```

返回规则：

- 任务状态为 `returned` 时返回 200 和最终 JSON。
- 任务还没有确认回传时返回 409。
- token 缺失或错误时返回 401。

最终 JSON 重点字段：

```text
job_id
external_order_id
status
campaign_payload
adset_payload
creative_payload
assets.images
assets.videos
review
```

外部系统用这些字段创建或填充广告投放数据。真实发布、账号选择、BM 授权、Pixel、素材入库和最终投放动作仍由外部系统或运营人员控制。

## 外部素材生成接口

如果外部系统不走完整工单审核流程，只需要 AI 系统直接生成素材，可以调用以下接口。

统一鉴权：

```http
Authorization: Bearer <AI_ADS_ACCESS_TOKEN>
Content-Type: application/json
```

也支持在 URL 上追加：

```text
?ai_access_token=<AI_ADS_ACCESS_TOKEN>
```

通用请求字段：

```json
{
  "external_request_id": "external-idempotency-key",
  "product_name": "Demo App",
  "landing_url": "https://example.com/landing",
  "audience": "New users who need a simple setup",
  "country": "US",
  "event_name": "registration",
  "customEventType": "COMPLETE_REGISTRATION",
  "language": "zh-CN",
  "brief": "Create clear material for daily use.",
  "selling_points": ["Simple setup", "Clear content"],
  "constraints": {}
}
```

说明：

- `external_request_id` 用于幂等，外部系统重试时建议保持不变。
- `product_name` 必填。
- `brief` 和 `selling_points` 至少传一个。
- `event_name` 如果包含“注册”或 `registration/register`，AI 系统会识别为 `customEventType = COMPLETE_REGISTRATION`。
- 文案、图片和视频请求都会做品牌安全检查，禁止赌博、博彩、药品、货币、价格、折扣、低价、免费等相关表达。

### 文案生成

```http
POST https://ai.ggcss.xyz/api/v1/integrations/material-generation/copy
```

成功时同步返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "request_id": "ai-copy-request-id",
    "primary_text": "Primary text",
    "headline": "Headline",
    "description": "Description",
    "cta": "Learn More",
    "customEventType": "COMPLETE_REGISTRATION"
  }
}
```

### 图片生成

```http
POST https://ai.ggcss.xyz/api/v1/integrations/material-generation/images
```

图片接口支持额外字段：

```json
{
  "count": 2,
  "size": "1:1"
}
```

成功时同步返回图片链接：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "request_id": "ai-image-request-id",
    "urls": [
      "https://ai.ggcss.xyz/storage/images/example.svg"
    ]
  }
}
```

### 视频生成

```http
POST https://ai.ggcss.xyz/api/v1/integrations/material-generation/videos
```

视频接口为异步创建，必须传参考图片：

```json
{
  "image_urls": ["https://ai.ggcss.xyz/storage/images/example.svg"],
  "duration_seconds": 6,
  "aspect_ratio": "9:16",
  "prompt": "Use a simple motion sequence."
}
```

创建成功先返回 `202`：

```json
{
  "code": 1001,
  "message": "processing",
  "data": {
    "job_id": "ai-video-job-id",
    "status": "processing"
  }
}
```

外部系统使用 `job_id` 轮询：

```http
GET https://ai.ggcss.xyz/api/v1/integrations/material-generation/jobs/<AI_VIDEO_JOB_ID>
```

视频完成后返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "job_id": "ai-video-job-id",
    "status": "succeeded",
    "url": "https://ai.ggcss.xyz/storage/videos/example.mp4"
  }
}
```

统一错误码：

```text
0    success
1001 processing
4001 validation error
4003 invalid or missing access token
4091 brand safety check failed
5001 provider error
```

## 投放成效分析回传

广告投放后，外部系统把广告效果数据回传给 AI 系统：

```http
POST https://ai.ggcss.xyz/api/v1/integrations/ad-performance/analyses
Authorization: Bearer <AI_ADS_ACCESS_TOKEN>
Content-Type: application/json
```

推荐 payload 包含：

```json
{
  "source_type": "external",
  "external_user_id": "operator-or-user-id",
  "metadata_json": {
    "ad_generation_job_id": "<AI_JOB_ID>"
  },
  "date_start": "2026-06-15",
  "date_stop": "2026-06-21",
  "campaign": {
    "name": "Campaign name",
    "fb_id": "facebook_campaign_id",
    "objective": "OUTCOME_TRAFFIC"
  },
  "adset": {
    "name": "Adset name",
    "fb_id": "facebook_adset_id",
    "countries": "US",
    "optimization_goal": "LINK_CLICKS"
  },
  "creative": {
    "name": "Creative name",
    "facebook_ad_id": "facebook_ad_id",
    "message": "Primary text",
    "headline": "Headline",
    "link": "https://example.com/landing",
    "image_url": "https://cdn.example.com/image.jpg",
    "video_url": "https://cdn.example.com/video.mp4"
  },
  "insight": {
    "impressions": "1079",
    "reach": "937",
    "clicks": "83",
    "inline_link_clicks": "86",
    "spend": "0.24",
    "actions": [
      { "action_type": "link_click", "value": "86" },
      { "action_type": "landing_page_view", "value": "23" }
    ]
  }
}
```

如果希望 AI 更准确分析素材画面，尽量提供：

```text
image_url
thumbnail_url
video_url
video_keyframes
```

如果希望判断真实业务效果，尽量提供：

```text
purchase
add_to_cart
lead
complete_registration
```

AI 系统会保存分析记录，并在投放分析页面展示：

- 已收到什么数据。
- 缺少什么数据。
- 当前能分析什么。
- 暂时不能分析什么。
- 大模型给出的原因诊断和优化建议。

## 第一阶段联调验收

建议按以下顺序验证：

1. 外部系统点击 `AI创建`，能打开 `https://ai.ggcss.xyz/work-orders/new?ai_access_token=<AI_ADS_ACCESS_TOKEN>`。
2. AI 系统能创建工单并进入审核流程。
3. 最终点击“确认并回传”后，浏览器跳到 `https://ads.ggcss.xyz/api/ai/receive_ai_ads`。
4. 回跳 URL 中包含 `job_id` 和 `status=returned`。
5. 外部系统用 `job_id` 调用最终 JSON 接口，能拿到 200。
6. 外部系统把投放效果数据 POST 到投放分析接口，AI 系统能生成分析记录。

## 后续增强方向

- 让 `AI创建` 入口追加 `external_order_id`，把外部广告记录和 AI 任务天然关联。
- 将回跳地址迁移到外部系统正式域名下的接收接口。
- 增加签名、nonce、幂等键和过期时间，减少 token 泄露和重复回传风险。
- 把投放分析结果反向生成下一轮 AI 优化工单。
